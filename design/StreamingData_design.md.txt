## Step 1: Analysis
Input : bitrateMbps , minutes
Process :
- Convert minutes to total seconds (seconds = minutes * 60)
- Calculate total megabits (megabits = bitrateMbps * second)
- Convert megabits to megabytes (megabytes = megabits / 8)
- Convert megabytes to gigabytes (gigabytes = megabytes / 1024) 
Output : totalMB, totalGB

Structure chart (module names and jobs):
main -> inputBitrate {...}, inputMinutes {...}, computeDataMB {...}, display {...}

## Step 2: Design
### Pseudocode
main
	CALL inputBitrate RETURNING bitrateMbps
	CALL inputMinutes RETURNING minutes
	CALL computeDataMB with bitrateMbps, minutes RETURNING totalMB, totalGB
	CALL display with totalMB, totalGB
 
inputBitrate
    PROMPT "Enter bitrate (Mbps): "
    READ bitrateMbps
    RETURN bitrateMbps

inputMinutes
    PROMPT "Enter duration (minutes): "
    READ minutes
    RETURN minutes

computeDataMB with bitrateMbps and minutes
	seconds = minutes * 60
	megabits = bitrateMbps * seconds
	totalMB  = megabits / 8
	totalGB = totalMB / 1024
	RETURN totalMB, totalGB

display (totalMB, totalGB)
	PRINT "Total Data Used: ", totalMB, " MB "
	PRINT "Total Data Used: ", totalGB, " GB "
